Crystal Defenders - CrystalDefendersRecomp
Unofficial native port for Windows. Written by an AI (Claude Code, Claude Opus 5.5).
Not affiliated with Square Enix. The game's data is not included: you need your
own copy of the game (Xbox 360, Xbox Live Arcade).

STARTING
  "Crystal Defenders" shortcut (desktop or Start menu), or crystal_defenders.exe.
  The settings screen (DarkLauncher) opens first: Play, Screenshots, Game,
  Achievements, Settings (Languages, Picture, Sound, Controls, Game folder,
  Defaults), Quit.
  It works with the keyboard, a controller or the mouse.

IN THE GAME
  Escape, or the controller's View button .... pause menu (resume, screenshot,
                                               settings, quit)
  F11 ........................................ full screen
  F12 ........................................ screenshot (captures folder)

CONTROLS
  Keyboard keys and controller buttons are chosen on the Controls page. Any
  XInput (Xbox-type) controller works without setup, and so do PlayStation 4
  and 5 controllers.

LANGUAGES
  Settings > Languages > Game language: the language of the game's texts (the
  game restarts). Settings > Languages > Menu language: that of the settings
  screen.

FILES
  userdata\ ................ saves and achievements
  captures\ ................ screenshots
  crystal_defenders.ini .... settings
  crystal_defenders.log .... log (the previous session: crystal_defenders.prev.log)
  game\ .................... the game's data, taken out of your copy

UNINSTALLING
  Windows Settings > Apps, or Uninstall.exe in this folder.
  Saves and game data are kept unless you tick the box.
