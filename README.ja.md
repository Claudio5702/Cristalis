# Cristalis

**Crystal Defenders Recomp — 静的リコンパイルによるネイティブ移植**

*[English](README.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Italiano](README.it.md) · **日本語***

![設定画面：ゲームの色合いに合わせた DarkLauncher](docs/screenshots/launcher-en.png)

このプロジェクトは、Xbox Live Arcade のゲーム「クリスタルディフェンダーズ」を Windows のネイティブ
プログラムとして動かします。ゲームの PowerPC コードを
[XenonRecomp](https://github.com/hedge-dev/XenonRecomp) であらかじめ C++ に変換し、このゲームのため
だけに書かれた小さなランタイムの上で実行します。Linux 版は試験的なものです。

このリポジトリにもリリースにも、**ゲームの素材は一切含まれていません**。画像・音声・音楽・テキストは
お手持ちのゲームから読み込まれます。リポジトリにはゲームのコードも含まれていません。変換されたコードは
プログラムのビルド時に `default.xex` から生成され、[リリースページ](https://github.com/Claudio5702/Cristalis/releases/latest)のプログラムもそうして
ビルドされています。**バージョン 1.04（ベータ版）**：まだ遊んだ人はごく少数です。

**クリスタルディフェンダーズ（Xbox 360）をご自身でお持ちである必要があります。** クリスタル
ディフェンダーズはスクウェア・エニックスの著作物です。このプロジェクトはスクウェア・エニックスとは
関係がなく、承認も受けていません。

## 遊び方

最新版は[リリースページ](https://github.com/Claudio5702/Cristalis/releases/latest)から、そこからだけダウンロードしてください：
Windows 用は `Cristalis-Setup.exe`、Linux 用は `Cristalis-linux-x86_64.tar.gz` です。

1. 本体からゲームをコピーします。本体のストレージにある `CRYSTAL DEFENDERS` フォルダー（または
   タイトル ID の `58410989` という名前のフォルダー）を、たとえば USB メモリーにコピーします。
2. インストーラーを使う場合：そのフォルダーを `Cristalis-Setup.exe` と同じ場所に置いて
   実行します。ゲームはそのフォルダーからインストールされ、ショートカットと Windows のアプリ一覧
   への登録も作られます。フォルダーがない場合は、インストーラーの最後の画面で場所を尋ねられます。
3. 自分でビルドし、インストーラーを使わない場合：`crystal_defenders.exe` を実行します。初回起動時にそのフォルダー
   （または `default.xex` と `Media` がすでに入っているフォルダー）を尋ねられます。プログラムと
   同じ場所にあれば、そのまま使われます。

ゲームのデータはプログラムの隣の `game` フォルダーに保存され、本体のフォルダーはもう必要ありません。
これらのファイルは他人に配らないでください。

Windows 10 または 11（64 ビット）、Direct3D 11 対応のグラフィックカード。

### 使用するゲーム

| | |
| --- | --- |
| タイトル ID | `58410989`（Xbox Live Arcade） |
| 本体のパッケージ | `58410989\000D0000\18F4739D37853F8596CE621540680922AFE9F23A`、58,126,336 バイト、SHA-1 `118C64C901976CD8E2B570D77B0A5E01C15C7A46` |
| その中の `default.xex` | 1,658,880 バイト、SHA-1 `31A90704D4233F6E730714515CD5F20BF08D7F0D` |

プログラムは `default.xex` が変換元のものと同じかどうかを確認し、違う場合はそれを知らせます。

## 機能

- **[DarkLauncher](kit/launcher) の中で動くゲーム**：Kahna（Bahamut
  Lagoon Recomp）のために作られたランチャーです。ゲームの前の設定画面と、プレイ中のポーズメニューを
  備え、7 か国語に対応し、キーボード・コントローラー・マウスで操作できます。見た目はゲームの
  アートディレクションに合わせています：ウィンドウの青、クリスタルの金色、星空。すべて DarkLauncher
  が自分で描いており、ゲームのファイルからは何も取り出していません。
- **ゲームの 6 つの言語**（フランス語、英語、ドイツ語、スペイン語、イタリア語、日本語）を設定で
  選べます。ゲームは新しい言語で再起動します。
- **グラフィックカードによる表示**：ゲームを 1280×720、1920×1080、2560×1440、3840×2160 で描画し、
  どのウィンドウサイズでもシャープ、なめらか、または輪郭をなめらかにして表示します。HDR（Windows）。
- **パソコンに保存される実績**：ゲームの上に通知が出て、設定画面に一覧があります。
- **本体のオフライン時の動作（任意）**：「Xbox LIVE に接続されていません」の表示と保存先デバイスの
  選択は、初期状態ではオフで、オンにできます。
- **スクリーンショット**：フィルターも含めて表示されたままの画像を保存し、設定画面で一覧できます。
- **コントローラー**：Xbox（XInput）、そして PlayStation 4 と 5 を直接読み取り（USB または
  Bluetooth）、どちらも振動に対応します。キーとボタンは「操作」ページで変更できます。PlayStation 3
  のコントローラーには DsHidMini ドライバーが必要です。
- **クラッシュレポート**：クラッシュ時にどこにいたか（「W1, Stage 2, Wave 5」）を次回起動時に記録します。
- **インストーラーとアンインストーラー**（6 か国語）。

## 設定画面

起動すると DarkLauncher の設定画面が表示され、プレビューの中でゲームが動いています。**プレイ**で
ゲームを始めます。プレイ中は **Esc**（またはコントローラーの View ボタン長押し）で、止まった画面の
上にポーズメニューが開きます：ゲームに戻る、スクリーンショット、設定、終了。

左側のバーには「プレイ」「キャプチャ」「ゲーム」「実績」「設定」が並び、一番下に「終了」があります。
選んでいる項目のページがその横に表示されます。Enter または右で中に入り、Esc で戻ります。

- **キャプチャ**：撮ったスクリーンショット（新しい順）。Enter で開き、Delete を 2 回押すとごみ箱に
  移します。
- **ゲーム**：「Xbox LIVE に接続されていません」の表示と保存先デバイスの選択（どちらもオフラインの
  本体と同じ動作。次回の起動から有効）。
- **実績**：ゲームの 12 個の実績と、それぞれの獲得日と条件。
- **設定**：ほかの項目へ進むページです。
  - **言語**：ゲームの言語（その言語でゲームが再起動します）とメニューの言語。
  - **画面**：内部解像度（1280×720、1920×1080、2560×1440、3840×2160）、プリセット、フルスクリーン、
    整数倍表示、グラフィックカードまたはソフトウェアによる表示、フィルター、HDR、垂直同期、フレームレート表示、「大きく表示して確認」、
    アクセシビリティ（ハイコントラスト、色覚フィルター、動きを減らす、大きなヘルプ）。
  - **サウンド**：音量とメニューの効果音。
  - **操作**：ゲームのキーボードのキーとコントローラーのボタン、振動、ショートカット。
  - ゲームのフォルダーと初期設定。

## 操作

キーは**物理的な位置**で決まります（日本語配列でも英語配列でも同じ位置）。すべて「操作」ページで
変更できます。

| ゲーム（Xbox 360） | キーボード（QWERTY の位置） | コントローラー（PlayStation） |
| --- | --- | --- |
| 方向パッド | 矢印キー | 方向パッド / 左スティック |
| A（決定）/ B（戻る） | X / Z | A / B（× / ○） |
| X / Y | S / A | X / Y（□ / △） |
| LB / RB | Q / W | LB / RB（L1 / R1） |
| Start / Back | Enter / 右 Shift | Start / Back（OPTIONS / SHARE）。Back 長押しでポーズメニュー |

`Esc`：ポーズメニュー — `F11` または `Alt+Enter`：フルスクリーン — `F12`：`captures\` に
スクリーンショット — `Tab`（押している間）：早送り。

## ファイル

すべてプログラムのフォルダーの中に置かれます。

| | |
| --- | --- |
| `game\` | ゲームのデータ（初回起動時にお手持ちのコピーから取り出したもの） |
| `userdata\` | ゲームのセーブデータと、獲得した実績の記録 |
| `saves\` | DarkLauncher の実績一覧（獲得日付き） |
| `captures\` | スクリーンショット |
| `crystal_defenders.ini` | 設定 |
| `crystal_defenders.log` | 前回のセッションのログ（`.prev.log`：その前のもの） |
| `crystal_defenders.ini.crash.txt` | クラッシュレポート（クラッシュ後の起動時に作成） |

## アンインストール

インストーラーでインストールした場合：ゲームのフォルダーにある `Uninstall.exe` を実行するか、
Windows の設定のインストール済みアプリ一覧から「Cristalis (Crystal Defenders)」を削除します。初期状態では、
再インストールに備えて、セーブデータ・設定・スクリーンショット・ゲームのデータはフォルダーに残り
ます。チェックボックスをオンにするとそれらも削除され、フォルダーごと消えます。インストーラーを
使わなかった場合：フォルダーを削除してください。

## Linux

**試験的。** glibc 2.35 以降の x86-64 Linux（Ubuntu 22.04、Debian 12、Fedora 36、SteamOS 3.5 以降）
向けのネイティブ版で、Windows と同じ DarkLauncher を使います：設定画面、ポーズメニュー、7 か国語、
コントローラー（Xbox と PlayStation、振動対応）、実績、テーマ。ゲームは OpenGL 3.3 で描画します。
システムの OpenGL、FreeType、fontconfig が必要です。SDL3 は `lib/` に同梱され、FFmpeg は組み込み
済みです。

1. Linux 版を展開します。
2. その中に `CRYSTAL DEFENDERS`（または `58410989`）フォルダーをコピーします。
3. `crystal_defenders.sh` を実行します。初回起動時にゲームがインストールされます。

これまで WSL（Windows の中で動く Linux）上でしか動かしていません（WSL 経由で実際のグラフィックカードを使用、コントローラーは
未使用）。実際の Linux デスクトップや Steam Deck ではまだ誰も試していません。DarkLauncher の Linux 版（ウィンドウ、メニュー、サウンド、コントローラー）も同じく新しく、同じ方法でしか試していません。Steam Deck では、
互換性ツールを強制せずに、`crystal_defenders.sh` を「Steam 以外のゲーム」として Steam に追加して
ください。Windows 版も Proton で動きます。

## 既知の制限

- オンラインのランキングはありません：Xbox LIVE が必要だったためです。パソコンに保存されるゲーム内のハイスコアは使えます。
- ステートセーブはありません：ゲームは独自のスレッドを持つ Xbox 360 のプログラム全体であり、
  自分でセーブします。
- 音楽のループは、本体独自の仕組みではなくランタイムが処理しています。
- これまでテストした人はごく少数です。コントローラーはキーボードほど試されておらず、PlayStation の
  コントローラーと振動は実機ではまだ試していません。

## よくある質問

**エミュレーターですか？** いいえ。ゲームのプログラムそのものを、あらかじめ PC 用のネイティブ
コードに変換しています（静的リコンパイル）。本体のハードウェアが行っていたこと（グラフィック、
XMA 音声、システムの機能）は Windows 用に書き直しています。

**なぜ自分のコピーが必要なのですか？** リポジトリにもリリースにも、ゲームの画像・音声・音楽・テキストは
含まれていません。プログラムは、正しいコピーであることを確認したうえで、お手持ちのコピーから読み込みます。

**本体のセーブデータは使えますか？** セーブデータは `userdata\` に、ゲーム独自の形式で保存されます。
本体と PC の間でセーブデータをコピーすることは試していません。

**インターネットに何か送信されますか？** いいえ。プログラムはネットワークを一切使いません。
